# DocWen Assistant

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru-RU.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md)

DocWen Assistant связывает Obsidian с локальной установкой [DocWen](https://github.com/ZHYX91/docwen). Требуются Windows или Linux, Obsidian 1.12.7 или новее и стабильная версия DocWen 0.17.0 или новее.

> **Требуется DocWen.** Установите совместимую версию из [Microsoft Store](https://apps.microsoft.com/detail/9NR2211SJH97) либо полностью распакуйте переносимый ZIP со страницы [DocWen Releases](https://github.com/ZHYX91/docwen/releases).

Язык интерфейса меняет только надписи и расположение элементов Assistant. Язык преобразования, шаблоны и OCR задаются параметрами задачи и настройками DocWen.

## Возможности

Плагин открывает файлы в DocWen, экспортирует Word/Excel/Markdown в явно выбранную папку, управляет нумерацией заголовков Markdown, выполняет проверку текста и предлагает команду **«Проверить подключение DocWen»**.

## Требования и совместимость

- Windows или Linux и Obsidian 1.12.7 или новее; плагин работает только на компьютере.
- В Windows используйте совместимую версию DocWen 0.17.0 или новее из Store либо полностью распакованный переносимый пакет; в Linux — полностью распакованный пакет, выбранный вручную. Для экспорта в Linux нужны x64 и файловая система, способная сохранять новые результаты без замены существующих данных; плагин не загружает DocWen автоматически.
- Плагину требуются `docwen.machine.v2` и `docwen.artifact_bundle.v3`; несовместимая версия DocWen отклоняется без перехода на другой протокол.
- Даже если подключение для фонового преобразования несовместимо, приложение DocWen можно попробовать открыть отдельно.

Если установленная версия из Store не соответствует этим требованиям, используйте совместимый переносимый пакет и выберите его в режиме ручной установки.

Автоматическое обнаружение доступно только в Windows и использует зарегистрированный псевдоним `docwen.exe`. В Linux требуется ручная установка; можно выбрать распакованную папку, `DocWen` или `DocWenCLI`. Плагин не ищет программы в произвольных папках и не загружает программы автоматически.

## Установка

### Установка DocWen и плагина

1. В Windows установите совместимую версию DocWen 0.17.0 или новее из [Microsoft Store](https://apps.microsoft.com/detail/9NR2211SJH97) либо распакуйте пакет Windows из [DocWen Releases](https://github.com/ZHYX91/docwen/releases). В Linux x64 полностью распакуйте пакет Linux с той же страницы.
2. Установите DocWen Assistant через Community Plugins. Для ручной установки скачайте `docwen-assistant-x.y.z.zip` со [страницы выпусков плагина](https://github.com/ZHYX91/obsidian-docwen-assistant/releases) и скопируйте `main.js`, `manifest.json` и `styles.css` в `<Vault>/.obsidian/plugins/docwen-assistant/`.
3. Перезагрузите Community Plugins и включите DocWen Assistant.
4. Версия Windows из Store определяется автоматически. Для переносимой версии Windows или Linux откройте **Настройки → DocWen Assistant → Общие**, выберите ручное подключение, затем распакованную папку или исполняемый файл.

### Сохранение настроек при обновлении

При ручном обновлении заменяйте только `main.js`, `manifest.json` и `styles.css`. Сохраните `data.json`, чтобы не потерять настройки; удаляйте его только для сброса. Имя папки должно оставаться `docwen-assistant`.

## Использование

**Доступные команды зависят от открытого файла.** Преобразование предлагается, только если подключённый DocWen поддерживает его для этого содержимого. Экспорт создаёт отдельную папку результатов, а проверка текста не изменяет заметку. **Добавление и удаление номеров заголовков изменяет Markdown.** Перед записью проверяется текущий текст редактора, включая несохранённые правки, либо сохранённый файл. Если нельзя однозначно выбрать один из нескольких редакторов того же файла, операция прекращается.

Значок, подменю **DocWen** и палитра команд позволяют запустить DocWen, экспортировать Word/Excel/Markdown, изменить нумерацию заголовков, проверить Markdown и выбрать **«Проверить подключение DocWen»**.

Выберите шаблон или профиль преобразования, если они предложены, затем папку вывода. Проверьте исходный файл, формат, папку и параметры и нажмите **Экспортировать**. Окно показывает настройки, полученные для этой задачи; отмена не запускает преобразование. Результат и связанные изображения сохраняются в новой папке. После завершения нажмите **Открыть папку результата** в уведомлении. Существующие папки результатов не заменяются.

## Настройки

Перед экспортом Word включите нужные **расширения ввода** в **DocWen → Настройки → Синтаксис Markdown**. В новой установке они отключены; набор ввода Obsidian включает связанную группу расширений.

| Содержимое или задача | Настройка DocWen |
| --- | --- |
| Объединённые ячейки Structural Tables | Расширение ввода Structural Tables |
| Подписи и ссылки Number Suite | Расширение ввода подписей и ссылок |
| Заголовки H7–H9 / типизированные концевые примечания | Соответствующие расширения ввода |
| Word в расширенный Markdown | Соответствующие расширения вывода |

Экспорт Word читает синтаксис Number Suite, даже если плагин не установлен. Номера в результате зависят от настроек DocWen, а не от номеров, которые Number Suite показывает только на экране. Отдельные команды добавления и удаления номеров заголовков меняют исходную заметку; экспорт её не меняет.

Настройки разделены на четыре вкладки: «Общие», «Экспорт в Markdown», «Экспорт в Word» и «Корректура». Пояснения находятся рядом с соответствующими параметрами. По умолчанию используется язык Obsidian; его можно изменить в общих настройках. Переключаться между вкладками можно стрелками и клавишами Home/End.

## Ограничения

- Для Windows или Linux на компьютере с совместимой локальной установкой DocWen; экспорт в Linux требует x64 и файловой системы, позволяющей сохранять результаты без замены существующих данных.
- Нет рекурсивного поиска за пределами выбранной папки или программы DocWen.
- Если заметка меняется во время обработки или результат нельзя безопасно сохранить, операция останавливается и просит проверить состояние файлов.

Преобразование в Word и обратно не заменяет резервную копию исходного Markdown. Поддерживаемое видимое содержимое можно восстановить, но неподдерживаемый синтаксис, встроенные заметки и часть оформления могут не сохраниться. Сохраните исходную заметку и проверьте результат обратного преобразования.

## Конфиденциальность и безопасность

Документы остаются на вашем компьютере. Плагин передаёт локальному DocWen временную копию выбранного файла, включая несохранённый текст, если ему соответствует один редактор. Добавляются только изображения, на которые явно ссылается заметка; плагин не ищет посторонние файлы по всему Vault и не загружает документы в сеть.

Экспорт сохраняет результат в выбранную папку. Проверка текста не меняет заметку. Нумерация записывается, только пока исходная заметка остаётся по тому же пути и её текст не изменён. Если во время обработки заметка была переименована или заменена, повторите команду для текущей заметки. Путь установки Store не сохраняется в настройках плагина. Технические подробности — в [спецификации интеграции](../cli-integration.md).

## Разработка

Используйте Node.js 24.19.0 и npm 11.17.0. Выполните `npm ci`, `npm run check` и `npm run release`. Исходный код находится в `src/`, тесты — в `tests/`; созданные файлы в `dist/` и `release/` не являются исходным кодом.

- Вопросы преобразования, OCR, проверки текста или поведения CLI вне Obsidian отправляйте в [DocWen Core Issues](https://github.com/ZHYX91/docwen/issues).
- Сообщайте об уязвимостях приватно в соответствии с [политикой безопасности](https://github.com/ZHYX91/obsidian-docwen-assistant/security/policy).
