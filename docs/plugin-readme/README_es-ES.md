# DocWen Assistant

Plugin de Obsidian para iniciar el convertidor DocWen.

## Instalación

1. Copia esta carpeta al directorio `.obsidian/plugins/` de tu vault de Obsidian
2. Recarga los plugins en la configuración de Obsidian
3. Habilita el plugin \"DocWen Assistant\"
4. Configura la ruta del ejecutable en los ajustes del plugin

## Uso

- Haz clic en el icono de documento en la barra lateral izquierda para iniciar DocWen
- Usa la paleta de comandos (Ctrl/Cmd + P) y busca \"DocWen\"
- Si hay un archivo abierto, su ruta se pasará automáticamente a DocWen

## Archivos incluidos

- `main.js` - Código principal del plugin
- `manifest.json` - Manifiesto del plugin
- `styles.css` - Estilos (si existe)
- `README*.md` - Documentación

Para más información, consulta la página de ajustes del plugin.
