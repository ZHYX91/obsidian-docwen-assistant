# DocWen Assistant - Плагин Obsidian

Плагин Obsidian для настольного приложения [DocWen](https://github.com/ZHYX91/docwen).

## ✨ Функции

### Основные функции
- ✅ **Быстрый запуск из боковой панели**: Добавьте иконку на боковую панель Obsidian для запуска одним кликом
- ✅ **Автоматическая передача файлов**: Автоматически передаёт путь к текущему открытому файлу в DocWen
- ✅ **Интеграция с палитрой команд**: Быстрый доступ через Ctrl/Cmd + P
- ✅ **Проверка пути**: Проверка пути к исполняемому файлу в реальном времени
- ✅ **Браузер файлов**: Легко выберите исполняемый файл через диалог просмотра
- ✅ **Обратная связь об успехе**: Дружественные уведомления при запуске
- ✅ **Управление единственным экземпляром**: Автоматически отправляет файл в работающий экземпляр
- ✅ **Многоязычная поддержка**: Поддержка 11 языков (zh-CN, zh-TW, en, de, fr, ru, pt, ja, es-ES, ko-KR, vi-VN)

## 📦 Быстрый старт

### Предварительные требования

1. **Установите Node.js**
   - Посетите [официальный сайт Node.js](https://nodejs.org/)
   - Скачайте и установите версию LTS
   - Проверьте установку: `node -v` и `npm -v`

2. **Установите зависимости**
   ```bash
   npm install
   ```

### Режим разработки

Используйте режим watch во время разработки для автоматической перекомпиляции при изменении кода:

```bash
npm run dev
```

### Сборка плагина

#### Быстрая сборка (без проверки типов)
```bash
npm run build:quick
```

#### Полная сборка (с проверкой типов и минификацией)
```bash
npm run build
```

#### Сборка релиза (автоматическая упаковка)
```bash
npm run release
# Или запустите напрямую: node scripts/build.js
```

Эта команда:
1. Скомпилирует код TypeScript
2. Создаст директорию release
3. Скопирует необходимые файлы
4. Сгенерирует инструкции по использованию

## 🚀 Установка в Obsidian

### Способ 1: Использование скрипта релиза (Рекомендуется)

1. Выполните сборку релиза:
   ```bash
   npm run release
   ```

2. Скопируйте папку `release/docwen-assistant` в:
   ```
   <Ваш Vault>/.obsidian/plugins/
   ```

3. В Obsidian:
   - Откройте `Настройки` → `Сторонние плагины`
   - Нажмите `Перезагрузить плагины`
   - Включите `DocWen Assistant`

### Способ 2: Ручная установка

1. Соберите плагин:
   ```bash
   npm run build
   ```

2. Создайте директорию плагина:
   ```
   <Ваш Vault>/.obsidian/plugins/docwen-assistant/
   ```

3. Скопируйте эти файлы в директорию:
   - `main.js`
   - `manifest.json`

4. Перезагрузите и включите плагин в Obsidian

## ⚙️ Настройка

1. Откройте Obsidian `Настройки` → `Сторонние плагины` → `DocWen Assistant`

2. Настройте путь к исполняемому файлу:
   - **Вариант 1**: Введите путь напрямую
   - **Вариант 2**: Нажмите кнопку `Обзор...` для выбора файла

3. Проверка пути:
   - ✓ Зелёный означает допустимый путь
   - ✗ Красный означает недопустимый путь или файл не найден

## 📖 Использование

### Запуск DocWen

Три способа запуска:

1. **Иконка боковой панели**
   - Нажмите на иконку документа в левой боковой панели

2. **Палитра команд**
   - Нажмите `Ctrl/Cmd + P` для открытия палитры команд
   - Найдите "Запустить DocWen"

3. **Запуск с текущим файлом**
   - Найдите "Запустить DocWen с текущим файлом" в палитре команд
   - Доступно только когда файл открыт

### Автоматическая передача файлов

- Если открыт файл Markdown, плагин автоматически передаёт его полный путь в DocWen
- Если файл не открыт, запускается только программа DocWen

### Управление единственным экземпляром

- **Первый клик** → Запуск DocWen и передача текущего файла
- **Повторный клик (с файлом)** → Замена на новый файл (Режим одного файла)
- **Повторный клик (без файла)** → Активация окна DocWen

## 🛠️ Скрипты разработки

### Доступные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Режим разработки (watch) |
| `npm run build` | Полная сборка (проверка типов + минификация) |
| `npm run build:quick` | Быстрая сборка (без проверки типов) |
| `node version-bump.js [patch\|minor\|major]` | Обновить номер версии |
| `npm run release` | Собрать пакет релиза |

### Управление версиями

Обновление номера версии:

```bash
# Патч-версия (1.0.0 → 1.0.1)
node version-bump.js patch

# Минорная версия (1.0.0 → 1.1.0)
node version-bump.js minor

# Мажорная версия (1.0.0 → 2.0.0)
node version-bump.js major
```

## 🐛 Устранение неполадок

### Плагин не загружается

1. Проверьте, правильно ли скопированы `main.js` и `manifest.json`
2. Нажмите `Перезагрузить плагины` в Obsidian
3. Проверьте консоль разработчика (`Ctrl/Cmd + Shift + I`) на наличие ошибок

### Не удаётся запустить DocWen

1. Проверьте правильность пути к исполняемому файлу
2. Подтвердите, что статус пути показывает зелёный ✓
3. Подтвердите, что исполняемый файл имеет правильные разрешения

### Путь к файлу не передаётся

1. Подтвердите, что файл в данный момент открыт
2. Проверьте, содержит ли путь к файлу специальные символы
3. Проверьте логи консоли на переданные аргументы
